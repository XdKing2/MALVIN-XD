### 🔑 Environment Variables

| Variable | Required | Description |
|---|---|---|
| `SESSION_ID` | ✅ | Your bot session ID from the pairing site |
| `MODE` | ✅ | `public` (anyone can use it) or `private` (owner only) |
| `TIME_ZONE` | ✅ | e.g. `Africa/Harare`, `Asia/Kolkata`, `America/New_York` |
| `MALVIN_API_KEY` | ✅ | Free key from [api.malvin.gleeze.com](https://api.malvin.gleeze.com) dashboard |
| `AUTO_LIKE_STATUS` | ➖ | `true`/`false` — auto-like statuses |
| `AUTO_READ_STATUS` | ➖ | `true`/`false` — auto-view statuses |
| `DATABASE_URL` | ➖ | PostgreSQL URL. Leave blank to fall back to SQLite |
| `OWNER_NAME` / `OWNER_NUMBER` | ➖ | Your name and number, shown as bot owner |

2. Click **New → Blueprint** and connect your fork.
3. Render reads `render.yaml` and **auto-provisions a free PostgreSQL** database (`malvin-db`).
4. Fill in `SESSION_ID` and `MALVIN_API_KEY` when prompted — everything else has defaults.
5. Click **Apply**.

> Render's free Postgres lasts 90 days. After that, grab a free external DB from [neon.tech](https://neon.tech) or [supabase.com](https://supabase.com) and paste it as `DATABASE_URL`. Leave it blank and the bot falls back to SQLite automatically.

**(E) VPS / SELF-HOSTED DEPLOYMENT**

<details>
<summary>TAP TO OPEN</summary>

> Requires a Linux VPS (Ubuntu 20.04+) with Node.js 20+ and Git installed.

**1. Clone the repo**
```bash
git clone https://github.com/XdKing2/MALVIN-XD.git
cd MALVIN-XD
```

**2. Install dependencies**
```bash
npm install
```

**3. Set environment variables**

Create a `.env` file in the project root using the variables from the table above.

**4. Install FFmpeg** (required for media commands)
```bash
sudo apt update && sudo apt install -y ffmpeg
```

**5. Start the bot**
```bash
npm start
```

**6. Keep it running with PM2** (recommended)
```bash
npm install -g pm2
pm2 start index.js --name malvin-xd
pm2 save
pm2 startup
```

**7. Update the bot**
```bash
git pull
npm install
pm2 restart malvin-xd
```
</details>
